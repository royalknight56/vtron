# Windows 应用入口与控制面板图标

图标采用公开源素材，没有从应用截图裁切或手工重绘。程序专用素材缺少时，使用 Windows 10 自带资源中语义相近的图标；这些入口不宣称全部与原生可执行文件图标逐像素相同。

Paint、Photos 和 Quick Assist 的原始透明图标来自 [Aaron Parker 的 Microsoft Store 图标归档](https://github.com/aaronparker/icons/tree/main/icons)：`MicrosoftStore-Paint.png`、`MicrosoftStore-MicrosoftPhotos.png`、`MicrosoftStore-QuickAssist.png`。

Windows Media Player 使用 [Beao 发布为公有领域的简化版经典标识](https://commons.wikimedia.org/wiki/File:Windows_Media_Player_simplified_logo.svg)。没有使用 Windows 11 新版 Media Player 图标。

其余 PNG 来自 [Windows UI Assets 的 Windows 10 资源](https://github.com/bartekl1/windows-ui-assets/tree/main/Icons/Windows%2010/ico)，由 ICO 原生 48px 帧导出；缺少 48px 帧时使用文件中最大帧。源素材版权及授权以源仓库说明为准。
